สิ่งที่แก้จริงใน src/index.css และ MapCanvas.tsx

  • --color-accent: #0d6efd → #0066cc (และ --color-accent-soft ตามไปด้วย)
  • .btn-primary / .btn-secondary: border-radius เปลี่ยนจาก var(--radius-md) เป็น 999px (pill), secondary เปลี่ยนจากพื้นทึบเป็น ghost (โปร่งใส + เส้นขอบ)
  • --shadow-card / --shadow-float: ลดความเข้มลง ให้สอดคล้องกับ "hierarchy จาก surface transition ไม่ใช่ shadow depth" ของ Apple
  • --font-sans: ขึ้นต้นด้วย -apple-system, BlinkMacSystemFont ก่อน Inter — เครื่อง Apple จะได้ SF Pro จริง ที่อื่นยังตกไป Inter เหมือนเดิม
  • ROUTE_COLOR / POSE_COLOR ใน MapCanvas.tsx (hardcoded hex เพราะ canvas 2D อ่าน CSS var ไม่ได้) แก้ให้ตรงกับ accent ใหม่ด้วย

ไม่ได้แตะ: รัศมีการ์ด/ชีต (--radius-sm|lg|xl), glass/glass-dark, การ์ดวางสินค้า 18px ของ Apple ยังไม่มีจุดที่ใช้ในแอปนี้
