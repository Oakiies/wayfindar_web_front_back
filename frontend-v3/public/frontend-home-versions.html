Wayfindar / UI review

หน้าแรกของแต่ละ Frontend

ภาพเทียบหน้า Map เริ่มต้นของทั้ง 3 รุ่น โดยใช้แผนผังชั้นจริงจากโปรเจกต์เดียวกัน เลือกชั้นด้านล่างเพื่อดูว่าหน้าหลักแต่ละเวอร์ชันจัดวาง search, floor rail และ bottom navigation อย่างไร

แสดงแผนผัง:

frontend

legacy

โทนอุ่นแบบเดิม แผนที่เป็นพื้นที่หลัก มี search bar ด้านบนและ bottom bar ขนาดใหญ่ด้านล่าง

frontend-v2

refined

เพิ่ม glass surface, active floor แบบ dark ink และ hit area ที่ชัดขึ้น พร้อม safe-area spacing

frontend-v3

current

รุ่นปัจจุบัน: paper palette, chrome ที่เบาลง, rail และ bottom nav ใช้ shape language เดียวกัน
