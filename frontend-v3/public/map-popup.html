พฤติกรรมที่ทำได้ตอนนี้

ลากย้ายตำแหน่งstartPopupDrag
ลากได้เฉพาะแถบหัว จับขอบจอไว้เสมอ — ห่างขอบอย่างน้อย 12px และไม่ขึ้นไปเหนือ y = 64 จึงไม่ทับปุ่มด้านบน
ย่อ / ขยายtogglePopupSize
แตะปุ่มมุมขวาบน หรือแตะที่ตัวแผนที่ก็ได้ ระบบแยกแตะออกจากลากด้วยระยะ 3px
ป้ายชั้นactiveFloorLabel
ชิปเล็กบนแถบหัว บอกชั้นที่กำลังแสดง — เป็นข้อความเดียวใน popup ทั้งหมด
จุดเปลี่ยนชั้นliveTransitionTarget
วงกลมตัวอักษร L เขียวสำหรับลิฟต์ / S ส้มสำหรับบันได โผล่เมื่อเส้นทางต้องข้ามชั้น
ไม่มี zoom / paninteractive = false
ใน popup ปิดการซูมและเลื่อนไว้ ต่างจากแผนที่เต็มจอที่เปิดทั้งล้อเมาส์ ลากนิ้ว และ pinch

สิ่งที่ยังขาด ถ้าเป้าหมายคือ “รู้ว่าฉันอยู่ไหน ปลายทางอยู่ไหน”

ทั้งสี่ข้อนี้อ่านจากโค้ดปัจจุบัน ไม่ใช่การเดา

01 ไม่มีคำอธิบายว่าอันไหนคืออะไร ไม่มี legend ไม่มีป้ายชื่อร้านปลายทาง ผู้ใช้ต้องเดาเองว่าวงน้ำเงินคือตัวเอง หมุดแดงคือปลายทาง
02 ไม่มีระยะทางหรือเวลาที่เหลือ ค่า routeMeta และ ETA แสดงอยู่บนการ์ดปลายทางในโหมดแผนที่ แต่ popup ไม่ได้รับค่าเหล่านี้เลย
03 แผนที่ไม่หมุนตามตัวเรา ผังชั้นตรึงทิศเสมอ มีเพียงลิ่มสีน้ำเงินที่หมุน และไม่มีเข็มทิศ/ตัวอักษร N บอกทิศเหนือไว้อ้างอิง
