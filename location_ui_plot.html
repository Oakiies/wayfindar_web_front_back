Location UI plot

ภาพรวมรูปแบบภาพที่ใช้บอกตำแหน่ง จุดเริ่มต้น จุดหมาย และจุดนำทางในระบบ WayfindAR

6รูปแบบภาพที่เกี่ยวกับการระบุตำแหน่ง
4 แบบบนแผนที่ + 2 แบบใน AR

บนแผนที่ 2D — 4 รูปแบบ

1

POI / จุดสถานที่

วงกลมสีเขียว พร้อม label ได้

variant: default
ใช้แสดงจุดสถานที่หรือจุดเปลี่ยนชั้นแบบย่อ เช่น L / S
2

Origin / จุดเริ่มต้น

วงแหวนกลวง + จุดกลางสีเข้ม

variant: origin / route alias
ใช้เป็นตำแหน่งต้นทางของ route เช่น “My location” หรือร้านต้นทาง
3

Destination / จุดหมาย

หมุดสีแดงทรง pin

variant: destination
ใช้ระบุร้านหรือจุดหมายปลายทางใน Store detail, Route planning และ Navigation
4

Current pose / ตำแหน่งผู้ใช้

จุดสีน้ำเงิน + cone/pointer แสดงทิศ

currentPose: { x, y, headingDeg }
ตำแหน่งจาก live localization; แสดงใน Navigation map และแผนที่ย่อบน AR

บน AR camera — 2 รูปแบบ

5

AR floor chevrons

ลูกศรสี cyan วางตามพื้นจริง

ar_world.chevrons
บอกทิศทางการเดินโดยผูกตำแหน่งกับภาพจากกล้อง (world-registered)
6

AR transition marker

marker ยกสูงสำหรับบันได/ลิฟต์

transitionTarget / ar_world.marker
จุด landmark สำหรับข้ามชั้น สีและ label แยกบันได (STAIRS) กับลิฟต์ (LIFT)
หมายเหตุการนับ
เส้น route และจุดถี่ ๆ บนเส้นทางเป็น “เส้นทาง” ไม่ใช่ตัวระบุตำแหน่ง จึงไม่รวมเป็นชนิดเพิ่ม ส่วน Split view มี type ในโค้ด แต่ถูกปิดด้วย showSplitViewOption = false จึงไม่นับเป็น UI ที่เปิดใช้จริง
