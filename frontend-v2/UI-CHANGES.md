# frontend-v2 — UI pass

Copy of `frontend/` (source only; `node_modules/` and `dist/` were not copied).
**UI layer only** — no state, effect, hook, service, routing or backend logic was
changed. Every prop signature is identical to `frontend/`, so the two folders are
drop-in interchangeable.

Design direction generated by the `ui-ux-pro-max` skill and persisted to
[`design-system/wayfindar/MASTER.md`](design-system/wayfindar/MASTER.md):
**Glassmorphism · route blue `#2563EB` · Inter · density 6/10 · motion 4/10**.

## What changed

### `src/index.css` — new token layer
Raw hex values were scattered across five components with no shared source of
truth. Replaced with a Tailwind v4 `@theme static` block:

| Group | Tokens |
|---|---|
| Surfaces | `canvas` `surface` `elevated` `sunken` `line` `line-soft` |
| Text | `ink` (17.7:1) `ink-2` (10.3:1) `ink-3` (5.98:1) |
| Accent | `accent` `accent-ink` `accent-soft` `accent-line` |
| Route | `origin` `dest` `warn` |
| Glass | `glass` `glass-line` (dark, for camera overlays) |
| Radius / shadow | `field` `card` `sheet` / `card` `sheet` `overlay` |

Every text token is verified ≥ 4.5:1 against `surface`, `canvas` **and**
`elevated`. The old greys (`#aaa` `#bbb` `#ccc` `#999` `#d0ccc6` `#c8c4be`
`#b0aa9e` `#c0bab2`) all measured between 1.6:1 and 4.2:1 and are gone.

Also added: global `:focus-visible` ring, `prefers-reduced-motion` handling,
`touch-action: manipulation` (kills the 300 ms tap delay), `overscroll-behavior`
(no accidental pull-to-refresh over the map), and `.tap` / `.press` / `.glass` /
`.glass-dark` component classes.

### Typography
Three different font stacks were in play — `DM Sans` (never loaded),
`Helvetica Neue`, and the browser default. Now one: **Inter**, loaded in
`index.html`, with a system fallback stack so it degrades cleanly offline.

### Touch targets
Every interactive control was below the 44 × 44 minimum — 38 px header buttons,
36 px floor chips, 34 px swap button, 24 px popup controls. All now use `.tap`
(44 px floor) or an explicit `min-h-[44px]`.

### Per screen

**MainMapView** — removed the decorative `X` inside the search bar (it looked
tappable and did nothing); floor rail buttons announce `aria-pressed`; bottom tab
bar became a real `<nav><ul>` with `aria-current` on the active tab.

**SearchView** — the trailing `X` used to duplicate the back button; it now
clears the query and only renders when there *is* a query. Search input raised to
16 px (below that, iOS Safari zooms the page on focus). Empty state gained a
"Search all floors" recovery action. Result list is now `<ul>/<li>`.

**StoreDetailView** — the Phone and Share buttons had no `onClick` and never did
anything, so they were removed and `Navigate` became the single full-width CTA.
**Put them back if they were placeholders for planned features.**

**RoutePlanningView** — From/To pickers gained visible labels (previously the
only labelling was a summary card lower down, which was also duplicating the same
two values — that card was removed). Walk-time estimate is now the largest type on
the screen and announces changes via `aria-live`.

**NavigationView** — camera-overlay chrome moved from `bg-white/20` (unreadable
over a bright frame) to `.glass-dark`, which holds 4.5:1 white text over any
video. Every icon-only button gained an `aria-label`; the mode menu is a proper
`role="menu"`. Fixed "AR Narvigate" → "AR Navigate". The `??` destination
fallback is now a real Lucide icon (design rule: no emoji as icons). Camera-error
state gained a "Try again" action. Safe-area insets applied for landscape AR.

**MapCanvas** — `role="img"` + `<title>` so the map has an accessible name;
route redrawn as white casing + solid blue core + travelling dashes that convey
direction of travel (animation disabled under reduced motion); marker colours
centralised in the exported `MAP_MARKER_COLORS`.

**App.tsx** — loading and error screens rebuilt with `role="status"` /
`role="alert"`; offline-data banner given a border and proper contrast.

Removed `src/App.css` (unused Vite boilerplate — nothing imported it).

## Not done

- `VideoTestPanel.tsx` and `ARFloorThreeOverlay.tsx` were left alone.
  `VideoTestPanel` is unreachable in the UI (`showVideoTestButton = false` in
  MainMapView) and `ARFloorThreeOverlay` is a three.js scene, not DOM UI.
- **Not built or run.** There is no Node.js runtime on this machine, so
  `npm run build` / `tsc -b` could not be executed. Verification was static:
  token-to-`@theme` cross-check, unused-import scan against `noUnusedLocals`,
  `calc()` syntax, WCAG contrast maths, and an accessible-name sweep.
  Run `npm install && npm run dev` in this folder to confirm.
